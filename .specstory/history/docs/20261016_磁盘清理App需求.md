# 开发者磁盘清理 App 需求与设计（macOS 27）

> 作者：ygw（由 Claude Sonnet 5.5 协助整理）

## 目标
简单、快捷、高效、并发检测；扫描极快；一眼看清磁盘占用；快速安全清理。

## 核心功能
- 项目级：由特征文件（Cargo.toml / pom.xml / build.gradle / package.json / *.xcodeproj / pyproject.toml / *.csproj / CMakeLists.txt 等）联动识别 target、build、node_modules、dist、.venv、obj/bin 等目录。
- 全局级：pnpm / yarn / npm / Maven / Gradle / Go / Cargo / pip / Homebrew / CocoaPods / Xcode（DerivedData、Archives、DeviceSupport）；Docker 与模拟器仅展示并给出命令引导。
- 清理等级：极力推荐（休眠项目，源码超过 90 天未改）/ 安全 / 需谨慎（需联网重下或可能被 Git 跟踪）/ 仅展示。
- 安全：废纸篓优先（可还原），永久删除需二次确认；清理前复核（路径、规则、白名单、.git）。
- Git 专项：.git 超过 100 MB 的仓库，提供 count-objects 分析、git gc、worktree prune，不删除仓库。

## 与原说明书的差异
1. 移入废纸篓不释放空间，结果面板提示并提供「打开/清空废纸篓」。
2. Docker 不允许直接移入废纸篓，仅引导 `docker system prune`。
3. 完全磁盘访问权限为非阻塞横幅，不授权也可使用。
4. 规则数据驱动，自定义规则使用同一 JSON 结构。
5. 硬链接按单个结果项去重（pnpm 节省的空间需所有链接都删除才真正释放）。

## 技术方案
- `CleanerCore`（SwiftPM）：规则、并发扫描（TaskGroup + 剪枝）、getattrlistbulk 体积计算、硬链接去重、活跃度早退探测、安全守卫、清理服务、Git 分析、JSON 持久化。
- `Cleaner`（SwiftUI App，XcodeGen 生成工程）：NavigationSplitView + inspector、统一工具栏、Liquid Glass、Canvas 矩形树图、Swift Charts 环形图。
- 非沙盒、Hardened Runtime；Bundle ID 固定为 `ixxxxoooo`，签名指定要求固定为 `identifier "ixxxxoooo"`，重新编译不会使完全磁盘访问授权失效。

## 性能实测（本机 ~，约 6.6 千目录、55 项）
- 首个结果约 0 秒，全量约 2–3 秒；与 `du` 对比体积偏差 < 0.2%。
